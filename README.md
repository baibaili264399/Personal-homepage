# 陆世松 · 个人主页

一个极简高级感的个人介绍网页，深色底 + 衬线大字 + 克制的微交互。

## 打开方式
直接双击 `index.html` 即可在浏览器打开（联网时自动加载 Google Fonts，离线时回退到系统字体）。

## 目录结构
```
portfolio/
├── index.html        # 页面结构 & 内容
├── assets/
│   ├── style.css     # 视觉样式
│   └── main.js       # 交互脚本
└── README.md
```

## 内容来源
内容基于你的《毕业生推荐表》整理：上海建桥学院 · 软件工程（2023.9—2027.6），Web 前端方向。
技能区按「前端开发 / 计算机基础 / 兴趣与拓展」分组，逆向工程、二进制分析、游戏安全放在兴趣拓展里。

## 想改的地方
